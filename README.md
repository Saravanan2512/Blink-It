# Blinkit Sales Analysis Dashboard

## Overview

This project presents an interactive Power BI dashboard built using Blinkit sales data. The dashboard helps analyze sales performance, customer satisfaction, and inventory distribution using business KPIs and visual analytics.

---

## Business Problem

Retail businesses need insights into sales trends, product performance, and outlet efficiency to improve revenue and inventory management.

This dashboard provides those insights through interactive visualizations.

---

## KPIs

- Total Sales
- Average Sales
- Number of Items
- Average Rating

---

## Dashboard Features

✔ Sales by Item Type

✔ Sales by Fat Content

✔ Sales by Outlet Size

✔ Sales by Outlet Location

✔ Sales by Outlet Establishment

✔ Outlet Type Analysis

✔ Interactive Filters
